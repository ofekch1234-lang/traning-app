# יומן הברזל 🏋️

אפליקציית מעקב אימוני כושר בעברית — תוכניות אימון, סטים ומשקלים, טיימר מנוחה, היסטוריה וגרפי התקדמות.

- **Frontend:** דף HTML סטטי יחיד (ללא build), מותאם לנייד (PWA).
- **Backend:** Supabase — הרשמה/התחברות (Auth) ושמירת נתונים לכל משתמש (Postgres + RLS).
- **Hosting:** Vercel (או כל אחסון סטטי).

## פריסה
אין צורך ב-build: לייבא את הרפו ב-Vercel כ-Static, וזהו.

כתובת ה-Supabase והמפתח הציבורי (publishable key) מוגדרים בראש `index.html`. המפתח הציבורי בטוח לחשיפה — ההרשאות נאכפות ב-RLS.
